## Требования к интеграции с платформой «Умный дом»

### 1. Требования к безопасности

- Все данные (команды, события, идентификаторы биометрии) должны передаваться по защищённому каналу HTTPS.
- Для серверного взаимодействия между PropDevelopment и платформой должен использоваться OAuth2.
- Все события доступа и команды должны логгироваться на стороне PropDevelopment с указанием даты, пользователя и источника.
- Биометрические данные (шаблоны лиц) хранятся исключительно на стороне партнёра в зашифрованном хранилище. В системе PropDevelopment сохраняется только UUID шаблона.

### 2. Протоколы аутентификации и авторизации

- Для доступа мобильного клиента к API PropDevelopment используется JWT токен сессии, получаемый после аутентификации.
- Взаимодействие между PropDevelopment и API партнёра защищено с помощью OAuth2.
- Биометрия пользователей связана с их аккаунтами через уникальные идентификаторы (`face_id`, `car_id`), сами данные не передаются в PropDevelopment.
- Управление доступом к шлагбауму и домофону осуществляется на стороне PropDevelopment на основе ролей и пользовательских настроек.

### 3. Взаимодействие между системами

- Мобильное приложение пользователя отправляет команды через API smart-home-integration.
- Система PropDevelopment авторизует пользователя, проверяет права доступа и перенаправляет команду в API партнёра.
- Устройства (домофон, шлагбаум) не взаимодействуют с системой PropDevelopment напрямую, а отправляют уведомления в платформу партнера, которая уже связывается с PropDevelopment по защищенным канал.
- События (распознавание, доступ, ошибки) формируются на стороне платформы и доставляются в PropDevelopment через Webhook или WebSocket.
- PropDevelopment обновляет информацию о жильцах и их правах доступа через защищённый API партнёра.
